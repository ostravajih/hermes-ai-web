Hermes Agent profily

10. července 2026 · 3 min

Profily umožňují běh více nezávislých instancí Hermes — každá s vlastní konfigurací, pamětí, dovednostmi a session historií. Ideální pro oddělení projektů.

Vytvoření

$ hermes profile create projekt-a $ hermes profile create klient-b --clone # Zkopíruje aktuální nastavení

Použití

$ hermes --profile projekt-a $ hermes profile use projekt-a # Nastavit jako výchozí

Správa

$ hermes profile list $ hermes profile show projekt-a $ hermes profile delete stary-profil $ hermes profile export projekt-a # Záloha do tar.gz

Typické použití

  • 💼 Práce vs osobní projekty
  • 👥 Různí klienti s různými API klíči
  • 🧪 Testování nové verze Hermes bez rizika
  • 🌍 Různé jazyky/regiony s různými modely
💼 Každý profil má vlastní ~/.hermes/profiles/NAZEV/ s kompletní konfigurací, skills, a pamětí.
