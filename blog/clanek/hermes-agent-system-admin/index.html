Hermes Agent pro systémové administrátory

10. července 2026 · 3 min

Hermes Agent je ideální pomocník pro správu serverů — od monitoringu po automatizaci rutinních úkolů.

Monitoring

/cron create "0 * * * *" "Zkontroluj CPU, RAM, disk. Pokud cokoliv nad 80 %, pošli alert."

Správa logů

$ hermes chat -q "Projdi /var/log/syslog za poslední hodinu a najdi ERROR a CRITICAL"

Bezpečnostní audit

$ hermes chat -q "Spusť bezpečnostní audit: zkontroluj otevřené porty, neúspěšné SSH pokusy, a navrhni opatření"

Automatizace

  • 🔒 Týdenní bezpečnostní audit
  • 📦 Automatické aktualizace balíčků (s review)
  • 💾 Zálohování s verifikací
  • 📊 Měsíční report o využití zdrojů
⚠️ Vždy používejte approval mode. Nikdy nespouštějte jako root. Pro produkční servery vytvořte dedikovaného uživatele s omezenými právy.

Kde pomůže nejvíc

  • Pravidelné kontroly, které se dají zapsat jako věta (disky, certifikáty, počet chyb v logu).
  • Hledání v logu a shrnutí: „co se dělo v noci“ místo ručního grepování.
  • Příprava změny: sepsat postup, porovnat konfiguraci, upozornit, co může spadnout.
  • Report, který si přečte i někdo jiný než vy (klient, šéf).

Kde naopak ne

Agent není pager ani střecha nad havárií. Když server hoří, potřebujete člověka s přístupem a plánem obnovy; agent může hlídat a upozornit, ale rozhodnutí i odpovědnost zůstávají na vás. Také nedělejte „automatické opravy“ bez schválení — dost často je rychlejší a bezpečnější vědět o problému.

Recepty na první týden

# ranní přehled — co se stalo v noci /cron create "0 7 * * *" "Shrň chyby z /var/log/nginx/error.log za posledních 24 h." # kontrola certifikátů, ať nepřekvapí vypršení /cron create "0 9 * * 1" "Zjisti datum vypršení TLS certifikátů na našich doménách." # hlídač záloh /cron create "0 3 * * *" "Ověř, že poslední záloha má dnešní datum a nejde o 0 bajtů."

Každý příkaz vložíte do chatu a potvrdíte Enterem — agent ho sám nikam neposílá. Schvalování nechte na produkci zapnuté a pracujte pod dedikovaným uživatelem.
