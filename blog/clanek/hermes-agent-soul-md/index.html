Osobnost agenta přes SOUL.md

10. července 2026 · 3 min

SOUL.md definuje identitu, chování a "osobnost" vašeho Hermes Agent. Je to markdown soubor v ~/.hermes/SOUL.md, který se načítá do system promptu při každém startu.

Vestavěné persony

$ hermes config set agent.personality technical # Dostupné: technical, friendly, concise, humorous, professional, surfer, hype, pirate, poet, ...

Vlastní SOUL.md

# ~/.hermes/SOUL.md Jsi AI agent specializovaný na DevOps a správu Linux serverů. - Odpovídej stručně a používej terminologii - Preferuj Bash před Pythonem pro skripty - Před každým destruktivním příkazem se ptej na potvrzení - Nikdy neodhaluj API klíče v odpovědích

Co lze v SOUL.md definovat

  • 🎯 Specializaci — "Jsi expert na databáze"
  • 🗣️ Komunikační styl — stručný/verbózní, formální/neformální
  • ⚠️ Bezpečnostní pravidla — co nikdy nedělat
  • 🔧 Preference nástrojů — jaké toolsety používat
💡 SOUL.md se načítá při každém startu. Změny se projeví po /reset v chatu nebo restartu.
