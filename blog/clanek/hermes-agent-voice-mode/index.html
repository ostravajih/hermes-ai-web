Hermes Agent hlasový režim

10. července 2026 · 3 min

Hermes podporuje obousměrnou hlasovou komunikaci — jak přepis řeči na text (STT), tak syntézu odpovědí (TTS).

Hlas v CLI (Ctrl+B)

Během chatování stiskněte Ctrl+B → mluvte → Hermes přepíše a odpoví.

Hlas na platformách

Na Telegramu a Discordu stačí poslat hlasovou zprávu — Hermes ji automaticky přepíše.

STT providery

ProviderCenaPoznámka
faster-whisperZdarmaLokální, potřebuje CPU/GPU
Groq WhisperZdarma (free tier)Velmi rychlý
OpenAI Whisper$0.006/minNejpřesnější

Konfigurace

# ~/.hermes/config.yaml stt: enabled: true provider: local tts: provider: edge # Zdarma, nebo: openai, elevenlabs
🎤 Pro lokální STT zdarma: pip install faster-whisper. Pro TTS zdarma: Edge TTS je výchozí a nepotřebuje API klíč.
