Hermes WebUI

10. července 2026 · 3 min

Hermes WebUI je komunitní webové rozhraní od nesquena (18.8k ⭐ na GitHubu). Poskytuje profesionální třípanelové rozložení pro správu Hermes Agent — podobné jako VS Code, ale pro vašeho AI agenta.

Co WebUI nabízí

FunkcePopis
🖥️ Třípanelové rozloženíSidebar se session, chat panel, file browser
🌙 Light + Dark režimPlynulé přepínání, respektuje systémové nastavení
🇨🇿 Česká lokalizaceKompletní překlad — všechny klíče, menu, dialogy
🔐 Heslová ochranaBezpečný přístup přes heslo nebo environment proměnnou
📱 Responzivní designPlně funkční na mobilu, tabletu i desktopu
🐳 Docker imageOficiální Docker image pro snadné nasazení
📂 File browserProcházení a editace souborů přímo z UI
💬 Multi-sessionVíce konverzací současně v záložkách

Instalace přes Docker (doporučeno)

# Stažení a spuštění $ docker run -d -p 3000:3000 --name hermes-webui nesquena/hermes-webui # S heslem $ docker run -d -p 3000:3000 -e PASSWORD=mojeheslo --name hermes-webui nesquena/hermes-webui # S perzistentními daty $ docker run -d -p 3000:3000 -v ~/hermes-webui-data:/app/data --name hermes-webui nesquena/hermes-webui

Po spuštění otevřete http://localhost:3000

Instalace přes Docker Compose

# docker-compose.yml version: '3.8' services: webui: image: nesquena/hermes-webui:latest ports: - "3000:3000" environment: - PASSWORD=mojeheslo volumes: - ./data:/app/data restart: unless-stopped
$ docker-compose up -d

Ruční instalace (Node.js)

$ git clone https://github.com/nesquena/hermes-webui.git $ cd hermes-webui $ npm install $ npm run build $ npm start

Připojení k Hermes Agent

WebUI se připojuje k běžící instanci Hermes Agent. Ujistěte se, že Hermes běží:

$ hermes

V nastavení WebUI zadejte URL vašeho Hermes API endpointu (výchozí: http://localhost:8080).

Nasazení na VPS s Nginx reverse proxy

server { listen 443 ssl; server_name webui.vase-domena.cz; location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; } }

Česká lokalizace

WebUI má plnou českou lokalizaci — všechny texty, menu, nastavení a dialogová okna jsou přeloženy. Pro aktivaci vyberte v Settings → Language → Čeština.
