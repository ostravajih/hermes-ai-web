Hermes Agent v Dockeru

8. července 2026 · Doba čtení: 4 minuty

Docker je ideální způsob, jak provozovat Hermes Agent izolovaně — bez ovlivnění zbytku systému. Hodí se pro testování, produkční nasazení i vývoj.

Výhody Dockeru

  • ✅ Izolace — agent nemůže ovlivnit hostitelský systém
  • ✅ Reprodukovatelnost — stejné prostředí na všech strojích
  • ✅ Snadná správa — docker-compose up/down
  • ✅ Perzistentní data — skills, paměť a konfigurace přes volumes

Instalace Dockeru

# Ubuntu/Debian $ sudo apt install docker.io docker-compose -y $ sudo systemctl enable --now docker # Přidání uživatele do skupiny docker (bez sudo) $ sudo usermod -aG docker $USER

docker-compose.yml

version: '3.8' services: hermes: image: hermes-agent:latest volumes: - ./hermes-data:/root/.hermes environment: - OPENAI_API_KEY=sk-... restart: unless-stopped
🔒 Nikdy nedávejte API klíče přímo do docker-compose.yml. Použijte .env soubor: env_file: .env
