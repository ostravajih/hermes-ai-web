Hermes Agent s Nous Portal

10. července 2026 · 2 min

Nous Portal je oficiální předplatné od tvůrců Hermes Agent (Nous Research). Jedna platba pokrývá všechno — LLM modely i nástroje.

Co získáte

  • 🤖 300+ modelů — Claude, GPT, Gemini, Llama a další
  • 🔍 Web search — přes Firecrawl
  • 🎨 Generování obrázků — FLUX
  • 🔊 Text-to-Speech — OpenAI TTS
  • 🎤 Speech-to-Text — Whisper
  • 🌐 Cloud browser — prohlížeč v cloudu

Jak začít

  1. Jděte na nousresearch.com/portal
  2. Vytvořte účet a vyberte plán
  3. V terminálu spusťte: hermes setup --portal
  4. Přihlaste se přes OAuth — žádné API klíče
$ hermes setup --portal
💰 Pokud využíváte více nástrojů (web search, obrázky, TTS), Nous Portal vyjde levněji než platit každé zvlášť. Plus získáte přístup k prémiovým modelům.
