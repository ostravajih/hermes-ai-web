Lokální modely

Model, který běží na vašem počítači: zdarma, bez odesílání dat a pomalejší. Kdy se vyplatí, co potřebuje a na co si dát pozor.

Lokální model je jako domácí pekárna: máte ji, nic neplatíte za každý bochník a nikdo se nedozví, co pečete. Ale trvá to déle a na složitý dort si radši zajdete do cukrárny. Přesně tak se k tomu stavíme — lokální model na soukromé a jednoduché věci, velký model v cloudu na to ostatní.

Nejjednodušší cesta: v aplikaci

  1. Otevřete Nastavení → Poskytovatelé → Lokální modely (nabídne se to i při prvním spuštění jako „Spouštět modely lokálně").

  2. Klikněte na Nainstalovat běhové prostředí. Stáhne se oficiální běhové prostředí pro váš hardware (pár set megabajtů), ověří se a bude se udržovat aktuální.

  3. Vyberte model z katalogu a klikněte na Stáhnout. U každého modelu předem vidíte, zda se vejde do paměti vaší karty (zelená), poběží přes operační paměť (oranžová), nebo je na váš stroj velký (červená).

  4. Klikněte na Použít. Nové rozhovory běží na lokálním modelu. Návrat k modelu v cloudu je jedno kliknutí ve výběru modelu.

Stahování se dá pozastavit a zase pustit — i po zavření aplikace zůstane rozdělané. Velké modely mají desítky gigabajtů, takže to na pomalém připojení chvíli trvá.

Když používáte Ollamu nebo vlastní server

Když už na počítači běží server (Ollama, vlastní llama-server, MLX), Hermes si ho najde a použije místo vlastního. Dá se to i nastavit ručně — stačí uvést adresu serveru:

# ~/.hermes/config.yaml providers: ollama: base_url: http://127.0.0.1:11434/v1 model: gemma3:12b # název modelu, který má Ollama stažený

Volitelně se dá zapnout i spravované běhové prostředí a určit, na kterých portech se má hledat:

local_runtime: enabled: true # spustit spravovaný server spolu s Hermesem backend: auto # auto | cuda | metal | vulkan | hip | cpu detect_ports: [8081] # další porty, kde hledat vlastní llama-server

Když server neběží, chyba to řekne přímo („lokální server modelu neběží") — nemusíte luštit hlášky o chybějícím klíči.
