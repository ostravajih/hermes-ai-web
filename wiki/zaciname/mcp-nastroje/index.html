Řada služeb už má hotové rozhraní pro agenty — agent se k němu jen připojí. Říká se tomu MCP a je to způsob, jak agentovi přidat schopnosti, které sám nemá: přístup k vašim souborům, k projektu na GitHubu, ke svému nástroji pro automatizaci nebo k prohlížeči. Nepíše se k tomu žádný kód.

Co to je, lidsky

Agent sám umí pracovat s terminálem, soubory a webem. Kdyby měl umět i všechno ostatní, musel by mít pro každou službu vlastní řešení — což je pomalé a křehké. MCP je společná dohoda, kterou už řada služeb nabízí. Agent se tedy připojí k hotovému rozhraní a hned umí to, co nabízí.

Přinese vámPříklad
Agent vidí do vašich systémůProjde soubory v projektu, přečte si dokumentaci, podívá se do databáze
Ovládá nástroje, které už používáteZaloží kartu v nástroji pro automatizaci, přidá komentář k úkolu, nahraje soubor
Umí se podívat na web jako člověkOtevře stránku v prohlížeči a ověří, že opravdu vypadá správně
Dosáhne na chyby a dokumentaciPřečte hlášené chyby z vašeho sledování, dohledá aktuální dokumentaci knihovny

Dva druhy napojení

DruhJak fungujeTypicky pro
MístníProgram se spouští přímo na vašem serveru, agent s ním mluví uvnitř počítačePřístup ke složkám, k databázi, k místnímu nástroji
VzdálenéAgent se připojuje přes internet k cizí službě; některé chtějí přihlášeníGitHub, project management, sledování chyb

Jak napojení přidat

  1. Z katalogu — nejjednodušší cesta. Pro vybraná napojení existuje katalog, ze kterého se instalují jedním příkazem:
    $ hermes mcp catalog $ hermes mcp install
    U některých napojení se při instalaci vybírá, které nástroje má agent vidět.
  2. Přidáním z adresy nebo příkazu. Když napojení v katalogu není:
    $ hermes mcp add
  3. Zápisem do nastavení. Ruční cesta pro toho, kdo ví, co dělá — do souboru ~/.hermes/config.yaml:
    mcp_servers: filesystem: command: "npx" args: ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projekty"]

U napojení, která chtějí přihlášení, se použije hermes mcp login — otevře se přihlášení v prohlížeči, stejně jako u kteréhokoli jiného účtu. Klíče se do nastavení nepíšou natvrdo: napojení si je bere z prostředí.

Ověření: hermes mcp test řekne, jestli se napojení podařilo připojit a jaké nástroje přineslo. Změny se projeví po novém spuštění agenta.

Bezpečnost: napojení je cizí kód

⚠️
Napojení dává agentovi nové schopnosti — a může v podstatě cokoli, co sám umí. Berte jen zdroje, kterým věříte (oficiální katalog, ověření výrobci) a u napojení, která to nabízejí, omezte, které nástroje agent uvidí. Napojení od neznámého zdroje je jako spustit cizí program s přístupem k vašemu serveru.
PojistkaCo dělá
Oficiální katalogNapojení v katalogu prošla kontrolou, takže je bezpečné začít tam
Výběr nástrojůU napojení se dá zaškrtnout jen to, co opravdu chcete používat — zbytek agent ani nevidí
Klíče mimo souborTajné údaje se berou z prostředí, ne z konfigurace, takže se nekopírují do záloh ani do gitu
