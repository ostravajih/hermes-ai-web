Skill je zapsaný postup — recept, který agent umí použít. Není to program ani instalace. Je to soubor s návodem, který si agent přečte, až když ho potřebuje. Napíšete jednou, jak má něco dělat, a agent to příště udělá stejně — i po měsíci, i v novém rozhovoru.

Co je skill (a co není)

CoCo to jePříklad
SkillNapsaný postup pro agenta: kdy ho použít, jaké kroky udělat, čeho se vyvarovat, jak ověřit výsledek„Jak u nás zálohovat databázi“
Nástroj (tool)Schopnost, kterou agent má — čte soubory, spouští příkazy, hledá na webuSpuštění příkazu v terminálu
PluginProgramové rozšíření samotného agenta (nová funkce v kódu). Píše se v PythonuNapojení na platební bránu

Pro většinu uživatelů stačí skilly. Plugin je něco, co programátor vyvíjí a udržuje — skill je jen prověřený postup v textu.

PřínosCo to znamená v praxi

Vaše know-how zůstane u vásSkilly jsou obyčejné soubory na vašem serveru ve složce ~/.hermes/skills/. Můžete je zálohovat i přesunout

Hotové skilly — kde je brát

Agent už má 58 hotových skillů a dalších 153 volitelných, které se doinstalovávají zvlášť. Podívat se a vybrat si můžete příkazem:

# prohlížení katalogu (klávesami nahoru/dolů, Enter vybere) $ hermes skills browse # co už mám k dispozici $ hermes skills list # hledání (funguje i v rozhovoru jako /skills search) $ hermes skills search záloha

Instalace jednoho skillu je jeden příkaz:

# volitelný skill z oficiálního katalogu $ hermes skills install official/research/arxiv # nebo přímo v rozhovoru $ /skills install official/creative/songwriting-and-ai-music
KategorieCo v ní najdete (příklady z hotových skillů)
DokumentyWord, Excel, PDF, prezentace — tvorba i čtení
Práce s kódemGitHub, kontrola změn, hledání chyb, spouštění testů

Nainstalovaný skill platí pro nové rozhovory. Když ho chcete použít hned uprostřed práce, spusťte /reset (nový rozhovor), nebo si vyžádejte okamžité načtení přepínačem --now — to je o něco dražší, protože se znovu načítá paměť rozhovoru.

Naučte agenta vlastní postup — i bez psaní

Nemusíte psát soubor ručně. Příkazem /learn řeknete agentovi, ať si postup sepíše sám — z dokumentace, z webové stránky, nebo z toho, co jste právě spolu udělali:

# z webové dokumentace $ /learn https://docs.example.com/api/quickstart # z postupu, který jste právě prošli spolu $ /learn jak jsme zálohovali databázi # z vlastních poznámek a souborů $ /learn naše pravidla pro zveřejňování článků

Agent si materiál projde, napíše z něj skill a od příště ho bude používat. Nic nemusíte umět programovat.

Jak vypadá vlastní skill

Skill je jediný textový soubor SKILL.md ve vlastní složce. Na začátku je krátké označení, podle kterého agent pozná, kdy má skill použít, a zbytek je návod:

--- name: zaloha-databaze description: Když se má zálohovat databáze našeho webu. --- # Záloha databáze ## Kdy použít Když se mluví o záloze, obnově nebo úpravě zálohovacího skriptu. ## Postup 1. Zastavit sběr dat. 2. Spustit zálohu příkazem … 3. Ověřit, že soubor vzniknul a není prázdný. ## Na co pozor Nezapisovat heslo do souboru se zálohou. ## Jak ověřit Soubor existuje, má nenulovou velikost a jde z něj obnovit testovací databáze.

Rozhoduje první věta. Agent se dívá hlavně na description — musí být krátká a musí říct, při jaké příležitosti se skill použije („Když se…“ / „Use when…“).

Naše tipy z provozu

TipProč
Pište konkrétní postup, ne obecné rady„Spusť tento příkaz a zkontroluj tento výstup“ je použitelné, „buď opatrný“ není
Jeden skill = jedna věcMalý a přesný skill se použije správně; obří se plete s ostatními
Doplňte, co se nepovedloNapsat do skillu chyby, na které jste narazili, ušetří hodiny příště
Přidejte, jak výsledek ověřitAgent si tak sám zkontroluje, jestli to udělal dobře (a vy taky)
Žádná hesla a klíče uvnitř skilluSkill je návod, ne trezor. Tajné údaje patří do nastavení agenta
Když se realita změní, přepište skillZastaralý skill je horší než žádný — agent se podle něj naučí špatný postup
Než nainstalujete cizí skill, přečtěte si hoSkill říká agentovi, co má dělat. Nainstalujte jen zdroj, kterému věříte, a text si projděte
