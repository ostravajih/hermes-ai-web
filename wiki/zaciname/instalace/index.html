Server po přihlášení sám nic nedělá. Žádný krok neproběhne automaticky — server jen čeká na příkazy. Každý příkaz z této stránky do okna terminálu vložíte vy (tlačítkem Kopírovat u bloku s příkazem a pak Ctrl+V, na Macu Cmd+V) a potvrdíte Enterem. Kroky 1 až 6 proto projděte jeden po druhém a vždy počkejte, až předchozí příkaz doběhne.

Proč vlastní server

Agent umí běžet i na vašem počítači, ale svoje schopnosti ukáže až ve chvíli, kdy pracuje pořád — sbírá data v noci, posílá vám zprávu ráno a má u sebe svoje nástroje a poznámky, i když je váš notebook vypnutý. Proto se vyplatí malý server (VPS).

Dobrá zpráva: stačí úplně obyčejný server za pár desítek korun měsíčně. Žádná grafická karta, žádný velký výkon — agent hlavně komunikuje s modelem přes internet.

Kde server pořídit: v Česku třeba Wedos, vpsFree nebo Active24 (platba převodem i kartou), ze zahraničí Contabo nebo Hetzner (platba kartou, vyjde levněji). Ceny se mění, proto si je před objednáním ověřte — na výběr se díváme v návodu Hosting pro AI agenta. Hledejte v nabídce „VPS" nebo „Cloud", ne „webhosting" — agent potřebuje vlastní systém, kde si sám instaluje, co potřebuje.

1. Objednejte server

V nabídce zvolte Ubuntu 24.04 LTS (nejlépe prověřená varianta), nejmenší tarif a pokud to jde, přidejte SSH klíč — bezpečnější než heslo. Po objednání vám přijde IP adresa, přihlašovací jméno a heslo.

2. Přihlaste se a připravte systém

Napište první příkaz — místo IP adresy dejte tu, kterou jste dostali e-mailem — a potvrďte Enterem:

# přihlášení na server $ ssh root@203.0.113.10

Příkaz se v ukázce vypíše sám a pod ním uvidíte, co server opravdu odpoví: uvítací zprávu a čekající kurzor. Server sám nic nespustí, jen čeká na další příkaz — kliknutím na okno si ukázku přehrajete znovu.

Teď napište druhý příkaz (opět ho vložte a potvrďte Enterem) — systém se aktualizuje:

# aktualizace systému $ apt update && apt upgrade -y

Pak si vytvořte vlastního uživatele a pracujte pod ním, ne jako root:

# vytvoření uživatele (jméno si zvolte) $ adduser hermes && usermod -aG sudo hermes
# přihlaste se jako nový uživatel a pokračujte v něm $ su - hermes

Proč ne jako root? Agent si v domovské složce drží konfiguraci, klíče a poznámky. Když ho spustíte jako root, všechno skončí ve složce roota — a s právy roota běží i případné chyby. Oficiální dokumentace to výslovně nedoporučuje.

3. Nainstalujte agenta

Instalaci spustíte jediným příkazem — vložte ho do terminálu a potvrďte Enterem. Instalátor si sám stáhne zdrojový kód a přinese i potřebné součásti (Python, Node, ripgrep, FFmpeg), takže na minimálním serveru není co doinstalovávat:

# instalace (Linux, macOS, WSL2) $ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Trvá to zhruba minutu. Na konci je potřeba znovu načíst prostředí shellu — jinak systém příkaz „hermes" ještě nezná. To je nejčastější chyba začátečníků a zároveň nejjednodušší oprava:

# načtení prostředí a kontrola $ source ~/.bashrc$ hermes --version

Volitelně je dobré spustit kontrolu prostředí, která poradí, co ještě chybí:

# kontrola instalace a doporučení $ hermes doctor

4. Vyberte model a přihlaste se

Agent potřebuje model — mozek, který přemýšlí. Dvě rozumné cesty:

# varianta A: jedno přihlášení přes Nous Portal (model i nástroje pod jedním účtem) $ hermes setup --portal
# varianta B: ruční výběr poskytovatele a vložení klíče $ hermes model

U varianty B si klíč vezměte u poskytovatele modelu (např. Nous Research, OpenAI, Anthropic, Google, OpenRouter) a vložte ho do schvalovacího formuláře, který se sám otevře. Vyberte model s kontextem aspoň 64 tisíc tokenů — menší Hermes odmítne spustit, protože by nezvládl svoje nástroje a paměť.

Nevíte, který poskytovatel se dá zaplatit z Česka a kolik to vyjde? Připravujeme stránku Výběr modelu a platba z Česka — zatím se ptejte v naší komunitě na Discordu.

5. První rozhovor

Napište jen hermes — otevře se rozhovor v terminálu. Zadávejte agentovi úkoly, u kterých si snadno ověříte výsledek:

# spuštění agenta $ hermes

Zkuste třeba: „Podívej se, kolik místa zabírá disk, a napiš mi to do tabulky." nebo „Najdi na serveru všechny soubory větší než 100 MB." Uvidíte, jak si agent sám spouští příkazy a hlásí výsledek.

6. Aby pracoval dál, když zavřete okno

Poslední krok je udělat z agenta službu, která se po restartu serveru zvedne sama. Slouží k tomu gateway — rozhraní, přes které agent přijímá zprávy (Discord, Telegram, e-mail) a běží na pozadí:

# nastavení a kontrola běhu $ hermes gateway setup$ hermes gateway status

Pokud nemáte práva roota, ať se služba spustí i po odhlášení, povolte takzvaný linger: sudo loginctl enable-linger $USER.
