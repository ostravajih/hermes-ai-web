A skill is a written procedure — a recipe the agent can follow. It is not a program and nothing gets installed in the usual sense. It is a document the agent reads when it needs it. Write down once how something should be done, and it will be done the same way next time — even months later, even in a new chat.

What a skill is (and is not)

ThingWhat it isExample
SkillA written procedure for the agent: when to use it, which steps to take, what to avoid, how to verify the result"How we back up the database"
ToolA capability the agent already has — reading files, running commands, searching the webRunning a terminal command
PluginA code extension of the agent itself (a new feature). Written in PythonWiring in a payment gateway

For most people skills are all they need. A plugin is something a programmer builds and maintains — a skill is just a proven procedure in plain text.

Why it pays off

BenefitWhat it means in practice
The procedure is followed every timeThe agent does not reinvent it — it reads your procedure. Fewer mistakes, less explaining
It costs nothing until neededThe agent only knows the names and descriptions. The full text is loaded when relevant — so you can keep dozens of skills
Your know-how stays with youSkills are plain files on your server in ~/.hermes/skills/. You can back them up or move them
The agent improves on its ownWhen something difficult works out, the agent can write a skill from it and repeat it next time

Ready-made skills — where to get them

The agent ships with 58 bundled skills and 153 optional ones you install yourself. To browse and pick:

# browse the catalog (arrow keys, Enter selects) $ hermes skills browse # what you already have $ hermes skills list # search (also works inside a chat as /skills search) $ hermes skills search backup

Installing one is a single command:

# an optional skill from the official catalog $ hermes skills install official/research/arxiv # or straight inside a chat $ /skills install official/creative/songwriting-and-ai-music
CategoryWhat you will find (examples of bundled skills)
DocumentsWord, Excel, PDF, presentations — creating and reading
Working with codeGitHub, reviewing changes, hunting bugs, running tests
Research and webVerifiable citations, RSS collection, watching pages, domain checks
CommunicationTriaging an inbox and drafting replies
Server operationsDocker, backups, monitoring, security
CreativeCharts, diagrams, images, simple animations

An installed skill applies to new conversations. To use it right away mid-task, run /reset (a fresh chat), or ask for immediate loading with --now — that costs a little more because the conversation memory is reloaded.

Teach the agent your own procedure — without writing code

You do not have to write the file yourself. The /learn command tells the agent to write it for you — from documentation, a web page, or from what you just did together:

# from online documentation $ /learn https://docs.example.com/api/quickstart # from a procedure you just walked through together $ /learn how we backed up the database # from your own notes and files $ /learn our rules for publishing articles

The agent gathers the material, writes the skill and uses it from then on. No programming required.

What your own skill looks like

A skill is a single text file SKILL.md in its own folder. It starts with a short label the agent uses to recognise when to apply it, followed by the procedure:

--- name: database-backup description: Use when the website database needs backing up. --- # Database backup ## When to use Whenever backups, restores or the backup script come up. ## Procedure 1. Stop data collection. 2. Run the backup with this command … 3. Verify the file exists and is not empty. ## Pitfalls Never write the password into the backup archive. ## Verification The file exists, has non-zero size and a test database can be restored from it.

The first sentence decides. The agent mainly looks at description — it must be short and say at what moment the skill applies ("Use when…").

Tips from experience

TipWhy
Write a concrete procedure, not general advice"Run this command and check this output" is usable; "be careful" is not
One skill, one thingA small precise skill gets applied correctly; a huge one gets confused with others
Record what went wrongWriting down the mistakes you hit saves hours next time
Add how to verify the resultThe agent then checks its own work (and so can you)
No passwords or keys inside a skillA skill is a procedure, not a vault. Secrets belong in the agent's settings
When reality changes, rewrite the skillAn outdated skill is worse than none — the agent learns the wrong procedure
Read a third-party skill before installingA skill tells the agent what to do. Only install sources you trust, and read the text first

When it does not work

SymptomCause and what to do
The agent does not use the skillThe description (first sentence) does not match the task — rewrite it to start with "Use when…" and to contain the words you actually use
A freshly installed skill does nothingIn a chat, skills load at the start of the session. Run /reset or request immediate loading
Two similar skills clashTwo skills share a name or an area. Rename or merge one of them
I do not know what the agent hashermes skills list (or /skills search) shows what is available; hermes skills audit checks the catalog state
A skill does something harmfulA third-party skill can contain a dangerous procedure. Delete it from ~/.hermes/skills/ and only take skills from trusted sources
