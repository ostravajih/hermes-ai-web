Quick start

Get it running in minutes.

No complicated dependency assembly. Install the agent, run setup and start using it.

# Install on Linux, macOS or WSL2
$ curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
$ hermes setup
$ hermes
