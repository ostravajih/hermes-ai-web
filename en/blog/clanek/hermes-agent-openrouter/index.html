Hermes Agent with OpenRouter

10 July 2026 · 3 min read

OpenRouter is an aggregator for LLM APIs — one account, one API key, access to 300+ models from every major provider. For Hermes Agent it is an ideal choice, because you can switch models without touching the configuration.

Why OpenRouter with Hermes?

  • ✅ One API key for Claude, GPT, Gemini, Llama and others
  • ✅ Automatic fallback — when a model fails, it moves to another
  • ✅ Transparent pricing — you pay only for the tokens you use
  • ✅ No minimum balance, no monthly fee
  • ✅ Price comparison across providers in one place

Step 1: Create an account

Go to openrouter.ai → click Sign Up → sign in with Google, GitHub or email.

Step 2: Get an API key

  • Once signed in, go to Settings → API Keys (direct link)
  • Click Create Key
  • Name the key (for example "Hermes Agent")
  • Optionally set a spending limit (we suggest $10–20 a month to start)
  • Copy the key — it starts with sk-or-v1-

Step 3: Top up credit

Go to Settings → Credits (direct link) → add credit (at least $5). OpenRouter draws from that balance as tokens are used.

Step 4: Configure Hermes

$ hermes model # → Provider: OpenRouter # → API Key: sk-or-v1-... (your key) # → Model: anthropic/claude-sonnet-4 (or any other)

Setting a fallback model

When the primary model fails (rate limit, outage), Hermes switches to a backup automatically:

# ~/.hermes/config.yaml # fallback_model: # provider: openrouter # model: google/gemini-2.5-flash

Tips for keeping costs down

  • Cheap routine, expensive logic: use Gemini Flash ($0.15/M) for ordinary questions and switch to Claude or GPT for hard tasks
  • Watch your usage: openrouter.ai/activity shows a detailed breakdown
  • Set a limit: under Settings → API Keys → Edit set a monthly cap so you never spend more than you meant to
💡 Suggestion: top up $10, point Hermes at Gemini Flash (the cheapest good model), and switch to Claude Sonnet by hand for difficult jobs. At ordinary usage $10 lasts one to three months.
