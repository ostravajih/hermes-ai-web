How to Use Skills in Hermes

July 8, 2026 · 6 min read

How Skills Work

Skills use progressive disclosure: Level 0 shows names only (~3k tokens), Level 1 loads full content when needed, Level 2 loads specific files.

Slash Commands

/github-pr-workflow create PR for auth refactor /plan /github-pr-workflow design and implement issue #42

Creating Skills with /learn

/learn REST API in ~/projects/api-docs /learn how I just set up CI/CD

Skills Hub

$ hermes skills install docker-deploy $ hermes skills list
💡 Skills are compatible with agentskills.io — share between Hermes, Claude Code, Codex, and others!
