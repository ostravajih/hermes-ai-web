Hermes Agent on všech platformách

10. July 2026 · 4 min read

Hermes Agent podporuje 20+ platforem z jedné gateway — stejný agent, stejná paměť, různé platformy.

  • 🎮 Discord — slash commands, reactions, threads

  • 💬 WhatsApp — Baileys bridge i Business API
  • 🔐 Signal, Matrix — encrypted communication
  • 📧 Email, SMS — traditional channels
  • 🖥️ CLI, WebUI, Desktop — direct access
