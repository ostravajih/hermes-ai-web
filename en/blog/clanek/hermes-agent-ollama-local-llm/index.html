Hermes Agent with a local LLM

10 July 2026 · 5 min read

Hermes Agent supports local LLMs through Ollama — free to run, offline, and completely private. Unlike cloud APIs you pay nothing per token, and your data never leaves your computer.

What is Ollama?

Ollama runs open-source LLMs locally (Llama, Mistral, Gemma, Qwen and others). It works on Linux, macOS and Windows (through WSL2). It handles model downloads, GPU acceleration and a REST API for you.

Installing Ollama

# Linux $ curl -fsSL https://ollama.com/install.sh | sh # macOS $ brew install ollama # Windows — through WSL2 (see our WSL2 article) $ wsl --install # if you don't have it yet $ curl -fsSL https://ollama.com/install.sh | sh

Downloading a model

Once installed, pull a model. We recommend Llama 3.1 8B for general use:

$ ollama pull llama3.1 # Other models worth trying: $ ollama pull mistral # 7B, fast, good at code $ ollama pull gemma2 # 9B, excellent at Czech $ ollama pull qwen2.5:7b # 7B, best at technical tasks

Configuring Hermes Agent

$ hermes model # → Select: "Custom OpenAI-compatible endpoint" # → Base URL: http://localhost:11434/v1 # → API Key: ollama (Ollama needs no real key) # → Model: llama3.1

Or by hand in ~/.hermes/config.yaml:

# model: # default: llama3.1 # provider: custom # base_url: http://localhost:11434/v1 # api_key: ollama

Ollama as a service (autostart)

# Start automatically after boot $ sudo systemctl enable ollama $ sudo systemctl start ollama # Verify that Ollama is running $ curl http://localhost:11434/api/tags

Performance tips

  • GPU acceleration: Ollama uses the GPU automatically (NVIDIA CUDA, AMD ROCm, Apple Metal)
  • Context window: 2048 tokens by default — for longer conversations raise it with /set parameter num_ctx 4096 inside ollama run llama3.1
  • Several models at once: Ollama can serve more than one, each taking its own RAM
  • Apple Silicon: on M1/M2/M3 it uses shared memory — a 16 GB MacBook Air handles even 13B models
⚡ The upside of a local LLM: no API fees, full privacy (data never leaves your computer), offline operation, unlimited use. The downside: you need stronger hardware, models are generally weaker than GPT-4o or Claude, and responses are slower.

Troubleshooting

Ollama will not start

Check whether the service is running: systemctl status ollama. If not, start it with ollama serve.

Hermes cannot reach Ollama

Verify the base URL: curl http://localhost:11434/v1/models. If Ollama runs in Docker, use http://host.docker.internal:11434/v1.

The model is slow

Try a smaller model (mistral instead of llama3.1) or a quantised build: ollama pull llama3.1:8b-instruct-q4_K_M.
