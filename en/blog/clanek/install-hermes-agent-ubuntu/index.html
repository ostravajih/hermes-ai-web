Install Hermes Agent on Ubuntu

8 July 2026 · 5 min read

Hermes Agent is an open-source AI agent by Nous Research that runs on your own server. Unlike cloud solutions, you have full control over your data, memory and configuration. This guide shows how to get it running on an Ubuntu VPS in under a minute.

What you'll need

  • A VPS with Ubuntu 22.04+ — even the cheapest 1 GB RAM one works (we recommend Contabo from €4.40)
  • An LLM API key — OpenAI, Anthropic, DeepSeek, OpenRouter or any compatible provider
  • SSH access to your server

Step 1: Connect to the server

Connect to your VPS over SSH:

$ ssh root@your-server-ip

Step 2: Run the installer

A single command installs everything you need — Python 3.11, Node.js, ripgrep, ffmpeg and Hermes itself:

# Install Hermes Agent $ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
💡 The installer works out what is missing and installs it. The only prerequisites are git, curl and xz-utils — usually already present on Ubuntu.

Step 3: Reload the shell and start

# Reload the shell $ source ~/.bashrc # Start interactive chat $ hermes

Step 4: Configure the LLM provider

On the first run Hermes walks you through the configuration. Choose a provider and enter your API key:

# Pick a model interactively $ hermes model # Or go through the whole wizard $ hermes setup

Supported providers: Nous Portal, OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, xAI Grok and dozens more.

Step 5: Set up a Telegram bot (optional)

Hermes can talk over 20+ platforms. The most popular is Telegram:

# Configure the messaging gateway $ hermes gateway setup # Start the gateway $ hermes gateway

The gateway runs in the background as a systemd service and survives a server restart.

Running 24/7 as a service

To keep Hermes running without interruption, install the gateway as a systemd service:

$ hermes gateway install $ systemctl --user enable hermes-gateway $ sudo loginctl enable-linger $USER

Minimum requirements

💾 RAM1 GB min, 2 GB recommended
⚙️ CPU1 vCPU minimum
💿 Storage10–20 GB SSD
🐧 OSUbuntu 22.04+, Debian 12+, or a modern Linux
🤖 GPUNot required — Hermes calls external LLM APIs

Troubleshooting

"hermes: command not found"

Reload the shell: source ~/.bashrc or exec bash

Missing API key

Run hermes model and choose a provider. The API key is stored in ~/.hermes/.env.

The gateway will not start

Check the log: tail -f ~/.hermes/logs/gateway.log

That's it! Your own AI agent is running on your server, with full control over your data and privacy.
