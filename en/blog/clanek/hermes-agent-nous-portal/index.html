Hermes Agent with Nous Portal

10 July 2026 · 2 min read

Nous Portal is the official subscription from the makers of Hermes Agent (Nous Research). One payment covers everything — both the LLM models and the tools.

What you get

  • 🤖 300+ models — Claude, GPT, Gemini, Llama and more
  • 🔍 Web search — through Firecrawl
  • 🎨 Image generation — FLUX
  • 🔊 Text-to-Speech — OpenAI TTS
  • 🎤 Speech-to-Text — Whisper
  • 🌐 Cloud browser — a browser in the cloud

How to start

  1. Go to nousresearch.com/portal
  2. Create an account and pick a plan
  3. In your terminal run: hermes setup --portal
  4. Sign in through OAuth — no API keys to handle
$ hermes setup --portal
💰 If you use several tools (web search, images, TTS), Nous Portal works out cheaper than paying for each separately — and you get access to premium models on top.

When it pays off

SituationNous PortalYour own keys
You want one account and one bill for everything✓Every service handled separately
You need web search, images and speech-to-text✓ includedFour separate sign-ups
You want spending visible per tokenLess granular✓ Every line item visible
You want a local model with no cloud✗✓ Ollama, llama.cpp

What stays with you

The agent and your data keep running on your own server — Nous Portal supplies models and tools, not hosting. Memory, files and skills stay in ~/.hermes. Sign-in happens over OAuth, so there are no keys in your config that could leak.

Verifying it works

$ hermes doctor $ hermes chat -q "Hi, which model are you running?"

If you see a sign-in error, repeat hermes setup --portal and log in again.
