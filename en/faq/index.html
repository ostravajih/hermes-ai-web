Frequently Asked Questions

Everything you need to know about Hermes Agent.

What is Hermes Agent?

Hermes Agent is an open-source autonomous AI agent by Nous Research (released February 2026). It runs on your own server, learns from every interaction, remembers context across days and weeks, and is available via Telegram, Discord, WhatsApp, terminal and 20+ platforms. Unlike chatbots, it's a standalone agent — it schedules tasks, runs them in the background, and notifies you when done.

How much does it cost?

Around €10–35/month: VPS from €5.50 + LLM API fees (€5–30). With cheap models like DeepSeek v3 or Gemini Flash's free tier, you can stay under €10.

What VPS do I need?

No GPU needed. Minimum 1 GB RAM, 8 GB recommended. Contabo VPS 10 (8 GB RAM, unlimited traffic) at €5.50/month is ideal.

How do I install it?

$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Is Hermes Agent free?

Software is free and open-source under the MIT license. The source code is publicly available on GitHub (253k+ stars). You only pay for your VPS and LLM API.

Does it support Czech language?

Yes! Both Hermes Agent and Web UI have full Czech localization. The Czech community actively maintains translations.
